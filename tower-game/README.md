# 🗼 NEON TOWER — じぶん専用タワーディフェンス

人気スマホゲーム「The Tower - Idle Tower Defense」のシステムを参考に、**自分だけで遊ぶため**に
一から作ったオリジナルのタワーディフェンスゲームです(コード・グラフィックはすべてオリジナル)。

> **ビルド不要・外部依存なし・オフライン動作。** `tower-game/index.html` をスマホやPCのブラウザで開くだけで遊べます。
> セーブは端末のローカルストレージに自動保存されます。

## 遊び方

- 中央の**タワーが自動で攻撃**。四方から迫ってくる図形の敵を迎え撃ちます。
- 敵を倒すと**キャッシュ($)**が手に入り、画面下のパネルでバトル中アップグレードを購入できます。
- タワーのHPが0になるとゲームオーバー。**コイン🪙は持ち越し**で、ワークショップの永久強化に使えます。
- 右上の「▶×1」で1〜3倍速を切り替えられます。

## バトル中アップグレード(キャッシュ)

| ⚔️ 攻撃 | 🛡️ 防御 | ⚙️ ユーティリティ |

| 攻撃速度 | 体力回復 | ウェーブ報酬 |

| 射程 | トゲ(反射) | 無料アップグレード |
| マルチショット率/数 | ライフスティール | 利子 |
| ラピッドファイア | ノックバック | ウェーブスキップ |
| バウンスショット | | |

## 永久強化・アルティメット武器

- **🔧 ワークショップ(コイン🪙)** — 基礎ダメージ・基礎体力・キャッシュ倍率などをバトルをまたいで強化。
- **☄️ アルティメット武器(ジェム💎)** — 解放するとバトル中に自動発動:
  - 🌊 **デスウェーブ** — 全画面の敵に大ダメージ
  - 👑 **ゴールデンタワー** — 15秒間キャッシュ獲得×4
  - 🕳️ **ブラックホール** — 敵を吸い込んで足止め
  - ⏳ **クロノフィールド** — 敵全体を50%減速
- HPが0になったとき、💎100で**復活**もできます(1バトル1回)。

## 🧪 チートメニュー(使い放題)

ホーム画面またはバトル中の「🧪」ボタンから:

- 💵 キャッシュ +100K / +100M
- 🪙 コイン +10K / +1M
- 💎 ジェム +1,000
- ❤️ タワー全回復
- 🛡️ ゴッドモード(無敵)
- 💥 一撃必殺(すべての敵を1発で倒す)
- ⏩ +10ウェーブジャンプ
- ☄️ アルティメット武器 全解放
- 🗑️ セーブデータ初期化

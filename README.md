# ⛏️ マインクラフト設計図メーカー

マインクラフトの建築の**設計図**をブラウザ上で作れるWebアプリです。テンプレートから自動生成したり、
グリッドに手で置いたりして建物を設計し、**層ごとの平面図**・**3Dプレビュー**・**必要ブロック集計**を
見ながら仕上げられます。作った設計図はJSON・PNG・テキストで書き出せます。

> **ビルド不要・外部依存なし・オフライン動作。** `index.html` をブラウザで開くだけで動きます。

---

## 特徴

- **多彩な建物テンプレート** — 家 / ビル / 小屋 / 塔 / 城 / 教会 / 宿屋 / 壁 / 橋 / 門・アーチ /
  井戸 / 噴水 / 灯台 / 鳥居 / 風車 / 鐘楼 / 市場の露店 / ピラミッド / ドーム / 球 / 温室 / 木。
- **立体的なディテール** — 木組みの家には、石の土台(巾木の張り出し)・軒の張り出し・妻壁・
  斜めの筋かい・出窓・バルコニー・煙突が付き、のっぺりしない凹凸のある外観になります
  (「装飾」チェックで切替)。
- **屋根の形を選べる** — 平屋根 / 切妻 / 寄棟 / 方形 / 和風(反り) / A字 / 片流れ / ドーム / なし。
- **オシャレ建築スタイル** — 中世ファンタジー(木組み) / コテージ / 山小屋 / 和風 / モダン / 西洋 /
  サバイバル素材 / デフォルト。壁・床・屋根の材料が切り替わります。中世系スタイルでは、実際の人気建築を
  参考に **木組み(柱・梁+白い漆喰)・石の土台・窓枠・煙突・軒の張り出したテラコッタ屋根** を自動で付けます。
- **用途別インテリア** — 家の用途を選ぶと内部に機能ブロックを自動配置。
  例:**倉庫**ならチェスト・樽・作業台・額縁だけ、**エンチャント部屋**ならエンチャントテーブル+本棚15個。
- **バージョン対応** — 対応バージョンを選ぶと、そのバージョンで使えるブロックだけに絞られます
  (古いバージョンでは自動でフォールバック。例:樽→チェスト)。
- **手動グリッドエディタ** — えんぴつ / 消しゴム / バケツ / 四角。層(Y軸)ごとに編集、オニオンスキンで下層を透過表示。
- **3Dプレビュー** — 自作のアイソメトリック描画。回転(4方向)・ズーム・ドラッグ移動。
- **必要ブロック集計** — 使ったブロックを種類ごとにカウント。スタック(64個)表示付き。
- **保存・書き出し** — JSON保存/読み込み、自動保存(localStorage)、PNG(3D/層)書き出し、テキスト書き出し。

## 起動方法

1. このリポジトリをダウンロード(またはクローン)します。
2. `index.html` をダブルクリックしてブラウザで開きます。

サーバーは不要です(`file://` で動作)。対応ブラウザ:Chrome / Edge / Firefox / Safari の最近のバージョン。

---

## 使い方

### テンプレートから作る
1. 左の「テンプレート生成」で**建物タイプ**を選びます。
2. タイプに応じた設定(サイズ・スタイル・屋根の形・用途など)が表示されるので調整します。
3. **「この設定で生成」**を押すと生成されます。そのまま手動エディタで手直しもできます。

### 用途別インテリア(家)
家・小屋で「用途(内装)」を選ぶと、内部の床に機能ブロックが自動で並びます。

| 用途 | 置かれるもの |
|------|--------------|
| 拠点(基本) | ベッド・作業台・かまど・チェスト |
| 倉庫 | チェスト・樽・作業台・額縁 |
| 作業場 | 作業台・かまど・溶鉱炉・燻製器・金床・砥石・石切台・チェスト |
| エンチャント部屋 | エンチャントテーブル+本棚×15・金床・書見台・チェスト |
| 醸造室 | 醸造台・大釜・本棚・チェスト |
| 寝室 | ベッド・チェスト・ランタン・書見台 |
| キッチン | 燻製器・かまど・樽・チェスト・コンポスター・大釜 |
| 図書館 | 本棚(壁一面)・書見台 |
| 鍛冶場 | 溶鉱炉・金床・砥石・鍛冶台・石切台・チェスト |
| なし | 内装なし |

### 手動エディタ
- **ツール**:えんぴつ(置く) / 消しゴム(消す) / バケツ(塗りつぶし) / 四角(矩形)。
- **ブロックパレット**でブロックを選択(対応バージョンで絞り込み)。
- **レイヤースライダー**で編集する層(Y=高さ)を切り替え。▲▼でも移動。
- **オニオンスキン**で1つ下の層を薄く表示し、位置合わせに使えます。
- **サイズ設定**で幅X・高さY・奥行Zを変更(縮小時は範囲外が削除されます)。

### 3Dプレビュー
- **回転**:見る向きを90°ずつ4方向。**＋/−**:ズーム。**画面に合わせる**:全体表示。
- キャンバスをドラッグすると視点を移動できます。

### 必要ブロック集計
使用中のブロックを種類ごとに集計します。数量はスタック単位(64個)でも表示されます
(例:`3スタック + 12個 (計204個)`)。

### 保存・書き出し
- **JSON保存 / 読み込み**:設計図を `.json` で保存・復元。
- **自動保存**:編集内容は自動でブラウザに保存され、次回開いたときに復元できます
  (`file://` で `localStorage` が使えない環境では無効になります)。
- **PNG(3D)**:3Dプレビューを画像で書き出し。**PNG(層)**:全層の平面図を1枚にまとめて書き出し。
- **テキスト**:層ごとのアスキー図+凡例+集計。チャットやメモへの貼り付けに便利です。

## バージョンとフォールバックの考え方

ブロックには「登場バージョン(`since`)」が設定されています。対応バージョンを選ぶと、それより新しい
ブロックはパレットから隠れます。テンプレート生成では、使えないブロックは**近い代替ブロック**に自動で
置き換わります(例:1.14未満なら 樽→チェスト、溶鉱炉/燻製器→かまど、コンクリート→同色の羊毛、
深層岩→石)。代替が無いもの(石切台・砥石など)は省略されます。

## ファイル構成

```
index.html        画面(HTML)と読み込み順の <script>
styles.css        スタイル
js/blocks.js      ブロック定義・バージョン・フォールバック
js/model.js       設計図データモデル(voxels[y][z][x])
js/templates.js   建物ジェネレータ・屋根・スタイル・用途別インテリア
js/iso.js         アイソメトリック3D描画
js/editor.js      平面(層)エディタとツール
js/materials.js   必要ブロック集計
js/storage.js     保存・読み込み・書き出し・自動保存
js/app.js         状態管理とUI配線
tests.html        ロジックの簡易テスト(開くだけで実行)
```

## データ形式(JSON)

```jsonc
{
  "version": 1,
  "name": "設計図の名前",
  "dims": { "x": 9, "y": 6, "z": 7 },   // x=幅, y=高さ, z=奥行
  "voxels": [ /* voxels[y][z][x] = ブロックid, 0 = 空気 */ ]
}
```

## 開発・テスト

`tests.html` をブラウザで開くと、フォールバック・生成・集計・保存往復などの簡易テストが実行され、
成功/失敗が一覧表示されます。ビルドやインストールは不要です。

---

## 制限事項

- 1辺の最大サイズは 96 ブロックです(性能のため)。
- ブロックの色は代表色で近似しており、テクスチャは表示しません。
- Java版のブロック名・可用性に準拠しています(統合版とは細部が異なる場合があります)。
